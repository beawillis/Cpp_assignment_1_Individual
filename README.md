# C++ Programming Assignment 1

A collection of small, standalone C++ programs covering fundamental programming concepts such as arithmetic operations, input/output handling, conditional logic, loops, geometry, and taxation calculations.

## Overview

This project contains six individual C++ programs designed to solve practical problems and reinforce core programming skills:

- BMI Calculator
- GIS Buffer Analysis
- Admission Letter / Mail Merge Program
- Population Projection
- Tax Calculation Program
- Triangle Area Calculator

Each file is independent and can be compiled and executed separately.

## Programs Included

### 1. BMI Calculator
File: `bmi.cpp`

Calculates a person's Body Mass Index (BMI) using weight in pounds and height in inches, then classifies the result as underweight, normal, overweight, or obese.

### 2. GIS Buffer Analysis
File: `buffer_area.cpp`

Computes the points located within one or more circular buffer regions around a specified center point.

### 3. Mail Merge Program
File: `mail_merge.cpp`

Generates a formal admission letter using user-provided details such as first name, last name, study program, and academic year.

### 4. Population Projection
File: `Population.cpp`

Projects a population estimate for the next five years using basic demographic assumptions for births, deaths, and immigration.

### 5. Taxation Program
File: `Taxation.cpp`

Calculates tax based on residence status and taxable income according to a structured income-tax rule set.

### 6. Triangle Area Calculator
File: `Triangle_area.cpp`

Computes the area of a triangle using three coordinate points and the Heron formula.

## How to Compile and Run

Use a C++ compiler such as `g++`.

### Example

```bash
g++ bmi.cpp -o bmi
./bmi
```

To run any other program:

```bash
g++ buffer_area.cpp -o buffer_area
./buffer_area
```

Replace the file name with the program you want to execute.
